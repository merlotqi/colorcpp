# colorcpp v0.3.0 Release Notes

Release date: 2026-05-14

## Highlights

- Debian packaging support is now available for Ubuntu/Debian users through a `libcolorcpp-dev` package.
- ANSI helpers are now stream-hygienic and define explicit behavior for small gradient step counts.
- `print_palette()` now supports a contiguous-container overload for C++17 code.
- Documentation now describes ANSI output as a terminal preview of converted `rgba8_t` values.

## New / Changed Behavior

### ANSI helpers
- `print_color()`, `print_color_verbose()`, and `print_contrast()` now restore the caller's formatting state.
- `print_gradient()` returns a single swatch for `steps == 1` and only a newline for `steps <= 0`.
- `print_palette()` accepts a contiguous container overload in addition to the pointer + count API.

### Documentation
- ANSI docs and examples now explicitly describe the conversion-to-preview model.
- The README ANSI example now uses the container overload.

### Debian packaging
- Added `debian/control`, `debian/rules`, `debian/changelog`, `debian/copyright`, and source format metadata.
- `debuild` / `dpkg-buildpackage` produce `libcolorcpp-dev` containing headers plus CMake and pkg-config metadata.

## API Compatibility

This release is source-compatible for existing consumers that call the existing pointer + count overloads and the existing ANSI helpers.
The following additions are new:

- `ansi::print_palette(std::ostream&, const Container&, int)` for contiguous containers

The following behaviors are now explicit rather than incidental:

- gradient behavior for zero/one steps
- stream formatting restoration after formatted ANSI output

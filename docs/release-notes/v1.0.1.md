# colorcpp v1.0.1 Release Notes

Release date: 2026-05-23

## Overview

v1.0.1 is the first stable release of colorcpp. It delivers a complete,
production-ready, header-only C++17 colour library with compile-time
colour-space conversions, a full CSS Color Module Level 4 parser, 16 blend
modes, perceptually uniform interpolation, colour-vision-deficiency simulation,
accessibility compliance checks, and much more.

## Highlights

- **Stable API** — All public namespaces, type names, and function signatures
  are now considered stable. Future 1.x releases will maintain backward
  compatibility.
- **Module hierarchy** — The library is organised into four top-level
  namespaces: `colorcpp::core`, `colorcpp::operations::*`,
  `colorcpp::algorithms::*`, and `colorcpp::io::*`.
- **28+ features** landed since v0.2.0, spanning colour-space conversion,
  blending, interpolation, palette generation, random colours, ΔE metrics,
  gamut mapping, gradients, harmony, accessibility, vision simulation, CSS
  parsing, serialisation, binary I/O, and ANSI terminal previews.
- **Cross-platform** — Tested on Linux (GCC, Clang), Windows (MSVC), and
  macOS (Clang) in CI. Builds with CMake 3.10+ and C++17.
- **Header-only** — No compilation required. `#include <colorcpp/colorcpp.hpp>`
  or pick individual module headers.

## API compatibility

v1.0.1 is source-compatible with v0.3.0. All public APIs present in v0.3.0
remain available. The following additions are new since v0.3.0:

None — v1.0.1 is a stabilisation release. All major features were delivered
in the v0.3.0 cycle and are now declared stable.

## Known caveats

- `blend()` evaluates in `rgbaf_t` (sRGB with transfer function). This is
  correct for opaque sRGB workflows but is not a proof of a linear-sRGB
  compositing contract. See the README blend section for details.
- `random_contrast_color()` is best-effort and may not satisfy its contrast
  constraint after exhausting its internal attempt budget.
- The experimental SIMD paths (`COLORCPP_ENABLE_EXPERIMENTAL_DELTA_E_OK_SIMD`,
  `COLORCPP_ENABLE_EXPERIMENTAL_VISION_MACHADO_SIMD`) remain opt-in and are
  not yet covered by the default CI matrix at the experimental granularity.
- CSS relative colour syntax currently supports `rgb(from …)` and
  `color(from …)`; `hsl(from …)`, `oklab(from …)`, and `oklch(from …)` are
  pending.

# colorcpp v1.0.6

Patch release with stability and correctness fixes across CSS parsing, gamut
mapping, interpolation, random generation, colour-space conversions, and CI.

## Highlights

- **CSS parsing**: bounded every recursive parse path so deep nesting fails
  cleanly; preserved slash alpha from `lab()`/`lch()`/`oklab()`/`oklch()`/
  `display-p3()`; capped channel-expression depth; serialize `rgbaf_t`
  channels as percentages for round-trip; resolve `from()` origins once.
- **Gamut mapping**: return the target-gamut clip result without an sRGB
  clamp; make preserve-saturation bisection effective while keeping alpha and
  grays; build perceptual results with `linear_rgbaf_t`; convert through XYZ
  for P3 / Adobe / ProPhoto membership; make the Adobe matrix pair mutually
  inverse and use the spec gamma.
- **Interpolation**: take the shortest hue arc with powerless substitution in
  generic lerp; treat powerless hues as missing in polar lerps and
  `color-mix()`; lerp in the caller's colour space instead of a clamped
  `rgbaf_t`.
- **Random generation**: guarantee the Poisson-disk min distance in the
  received colour; advance the Poisson engine across calls and guard
  `min_distance <= 0`; gamut-map in OkLab before casting to the target type.
- **Colour-space conversion**: route device-independent spaces through XYZ,
  not clamped RGB; wrap hue before sector cast and define a NaN policy for
  integral construction; map NaN to channel min on integral targets.
- **Core colour spaces**: widen Luv u/v, Lab a/b/C and XYZ ranges so
  conversions stop clipping; widen OkLab/Lab ranges and decouple random
  sampling domains.
- **CI**: add ARM64 and FreeBSD build and test jobs; enhance the FreeBSD
  build configuration with environment variables.

## Installation

colorcpp is a header-only C++17 library. Add `include/` to your include path
or install via CMake:

```cmake
find_package(colorcpp REQUIRED)
target_link_libraries(your_target PRIVATE colorcpp::colorcpp)
```

Or consume the headers directly:

```cmake
add_subdirectory(path/to/colorcpp)
target_link_libraries(your_target PRIVATE colorcpp::colorcpp)
```
